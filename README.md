# ת״ת תומכי תורה — ישיבת דעת אהרן

## פרסום מקוון

פרסום Sites מנוהל מתיקיית `.site-deploy` המקומית, בנפרד ממאגר המקור ב־GitHub. מזהה האתר: `appgprj_6aecd7bc97308191b6a5284c84a78754`. אין ליצור אתר נוסף בעת עדכון. מניפסט הפרסום נמצא ב־`.site-deploy/.openai/hosting.json` והתוכן הסטטי ב־`.site-deploy/dist`. לפני פרסום שינוי צריך לסנכרן את קובצי האתר והנכסים לתיקייה זו ולפעול לפי תהליך Sites עם אותו מזהה אתר.

## תמונת פתיחה

`entrance.js` ו־`entrance.css` מוסיפים לדף הבית תמונת המחשה של חנות ביגוד, עם שכבת זכוכית כחולה שקופה ומטושטשת והלוגו המקורי מעליה. התמונה ב־`assets/store-entrance.png` נוצרה באמצעות ImageGen המובנה; היא אינה צילום של החנות בפועל.

Prompt: Photorealistic wide interior photograph of a modest men's clothing boutique in Jerusalem. Neatly hung white shirts, black/navy suits, black leather shoes and folded shirts on warm wood shelving. No people, logos or readable text. Natural warm daylight, entrance perspective, landscape 16:9; uncluttered central area for a separately implemented blue frosted-glass logo panel.

## דפי מוצר

לחיצה על שם המוצר, התמונה או כפתור בחירת האפשרויות פותחת `#product/<id>`. `products.js` ו־`products.css` מוסיפים אפשרויות מידה, צבע וכמות לפי סוג פריט. מידות וצבעים כרגע להמחשה ומסומנים כך; אין נתוני מלאי מאומתים. בחירות שונות מקבלות מזהה שורת סל נפרד, והמידה, הצבע והכמות נשמרים בדפדפן יחד עם הסל. המחיר נלקח מהקטלוג הרשמי.

## הסדרי חנויות ולוגו מעודכן

עמוד `#stores` מציג שישה קופוני דמה, עם סינון, חיפוש והעתקת קוד. נתוני ההסדרים נמצאים ב־`stores.json`; לאחר עריכתם, `npm run build` מסנכרן גם את `stores-data.js`. שמות, טלפונים והטבות כרגע להמחשה בלבד. פעולת חיוג למספרי הדמה חסומה בממשק.

כל מופעי הלוגו באתר משתמשים ב־`assets/tomchei-torah-logo-clean.png`, גרסה מעובדת עם שקיפות אמיתית. פירוט כלי העיבוד והפרומפט נשמר ב־`assets/logo-processing.md`. הלוגו המקורי נשמר בנפרד. אזור הפתיחה הגדול והפס העליון הוסרו לטובת חיפוש וגישה ישירה לקטלוג.

חנות חדר ביגוד וחדר צצ״א לבחורי הישיבה, לבוגרים ולמשפחותיהם. האתר פועל מקומית, ללא DB או שירות הזמנות בשלב זה.

## הפעלה

`npm start` — פתיחה בכתובת http://localhost:3000.

`npm install` נדרש רק אם חסרות תלויות. `npm run build` מסנכרן את הקטלוג ובונה את CSS.

## מוצרים ומחירים

`catalog.json` הוא מקור הנתונים לעריכה: 54 מוצרים ותוספות שתומללו ממחירון זמן חורף פ״ז. אחרי עריכה יש להריץ `npm run build`; הוא מייצר את `catalog-data.js` שהאתר טוען. המבנה כולל מזהים קבועים, קטגוריות, מחירים ותמונות, ומוכן לשמש נתוני התחלה לחיבור עתידי ל־DB.

קובץ המחירון המקורי נמצא ב־`assets/winter-pricelist.pdf`. הלוגו ב־`assets/tomchei-torah-logo.png` חולץ מהתמונה המקורית שבתוך ה־PDF, נחתך בנפרד מהמסגרת, הוגדל עם חידוד עדין והוסר ממנו הרקע הבהיר. זהו קובץ רסטר, ולא לוגו וקטורי משוחזר.

## קבצים

- `index.html`: שלד האתר וחלוניות.
- `app.js`: לוגיקת סל, חיפוש, ניווט ושמירה מקומית.
- `redesign.js`: תשתית מסכים ורכיבי תצוגה.
- `shop.js`: מסכי ת״ת הישיבה, המיתוג והקטלוג הרשמי.
- `refinements.css`: פריסה ועיצוב בסיס.
- `brand.css`: צבעי כחול וזהב, לוגו והתאמות למותג הת״ת.

הסל והמועדפים נשמרים בדפדפן. סיכום בחירה אינו שולח הזמנה או מבצע חיוב. אין התחברות, סנכרון משתמשים או נתוני מלאי חיים. זמינות, מידות ושעות איסוף יש לברר מול החנות. תמונות המוצרים הן להמחשה; לפריטים ללא תמונה מתאימה מוצג מציין מקום. תיקיות הייצוא המקוריות מ־Stitch נשמרו.
